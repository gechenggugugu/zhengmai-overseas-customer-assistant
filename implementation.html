部署与接入说明

数据来源

演示模式里的公司、联系方式和 .example 链接都是虚构样本，仅用于体验功能，不能当作真实客户。真实搜索只调用配置的服务端接口；后端未配置或用户未登录时会报错，不会回退到演示样本。真实结果保留公开来源链接，使用前应核验。

页面现有搜索、筛选、去重、收藏、跟进历史、CSV 导出和英文邮件草稿在 Windows 本地版和线上版共用同一套业务代码。

Windows 本地运行

解压启动包后双击 start-windows.bat。它使用 Windows 自带 PowerShell 在本机启动网页并打开浏览器；不需要安装 Node.js、npm 或数据库。关闭启动窗口即可停止服务。免安装包和在线部署加载同样的页面、服务逻辑和配置文件。

启用跨设备同步时，本机也须通过 http://127.0.0.1:4173 启动，以便 ES 模块与登录回调正常工作；file:// 直接打开不支持此版本。

GitHub Pages 在线发布

正式网址：https://gechenggugugu.github.io/zhengmai-overseas-customer-assistant/。源码仓库：GitHub 项目。本项目由 main 分支根目录发布。更新源码后，在仓库 Settings → Pages 检查分支为 main、目录为 /(root)。静态演示无需环境变量或 API 密钥。GitHub 官方的分支发布说明介绍了配置方法。该仓库为公开仓库，源码对所有人可见。

邮箱登录和跨设备同步

云端功能基于 Supabase Auth 与 Postgres。先创建 Supabase 项目，执行 backend/supabase/migrations/20261126000100_lead_records.sql，部署 Edge Function，并在 public-config.js 填项目 URL 和 publishable/anon key。该 key 会出现在浏览器中，只有配合启用的行级安全（RLS）才可公开使用；SQL 已按登录用户限制每行的读写权限。浏览器不会拿到 Supabase secret/service-role key。

配置 Auth 邮箱验证邮件和允许回跳地址：GitHub Pages 项目主页、本机 http://127.0.0.1:4173。配置完成后，不同电脑登录同一账号后，收藏、跟进状态、备注和历史会同步。访客数据保存在原浏览器，登录后可主动点导入按钮；不会静默并入账号。SDK 使用 PKCE 和 sessionStorage，会话在标签页关闭后通常结束；同源 XSS 仍有机会读取会话，CSP 与动态文本转义用于降低风险。

Supabase 免费层标价为 $0，但长期不活跃的免费项目会被暂停。无需付费升级；本次没有创建 Supabase 项目、启用付费服务或提交付款信息。请查看 当前价格与免费层限制。

国家选择和真实搜索

国家/地区单选列表由 backend/supabase/functions/_shared/markets.json 统一维护，包含 ISO 3166-1 两位代码以及中文、英文名称。页面支持按中英文名称或代码搜索、249 个国家/地区列表、常用市场快捷选择和“全部市场（全球搜索）”。真实搜索把 ISO 代码发给后端；Tavily 需要英文国家名称而非代码，只对其 API 支持的地区发送国家参数，其他地区仍把国家名称加入搜索词。未选择国家时不设置国家筛选。每次用户操作仍只发一个 Tavily basic 查询，产品、国家和进口商/经销商/批发商扩展词组合在同一查询中；结果按规范化站点主机名去重。Brave 仅对配置为支持的既有 11 个国家发送 ISO 代码，其他地区通过关键词定位。

真实搜索保留搜索标题、站点、摘要、来源 URL 和摘要中实际出现的邮箱。公司主体、官网、国家和客户类型分别标记待核实状态；未在摘要出现的联系方式保持空白。规则初筛标明评分依据；配置可选 AI 服务后，会以搜索证据评分并生成英文草稿，草稿不会自动发送。

Edge Function 验证 Supabase 登录会话。服务端强制每用户每天 5 次、整个项目每月 150 次；每次 Tavily basic 搜索通常消耗 1 credit。达到上限立即停止，不自动追加付费额度。在 Supabase Edge Function Secrets 设置 SEARCH_PROVIDER=tavily、SEARCH_API_KEY 和 APP_ORIGINS，搜索供应商 key 仅存服务端。可选 AI API 必须三项服务端变量齐备才会调用；模型服务可能收费。不要把搜索密钥、Supabase secret/service-role key 写进源码。部署步骤见 后端部署说明。
